## 💡 About The Project

**DreamersDesire Crafts** is my cozy corner of the web where curiosity turns into code. Rather than letting spontaneous creative ideas, interactive UI concepts, and mini-applications sit idle in scattered repositories, this project serves as a single unified playground to build, showcase, and iterate on them.

### Why Crafts?

- 🎨 **Play & Experiment:** Testing novel UI patterns, animations, canvas interactions, and web APIs without production constraints.
- 🛠️ **Micro-Utilities:** Small, purposeful tools designed to solve specific daily problems or scratch a quick creative itch.
- 🚀 **Modern Tech Explorations:** Staying sharp with the latest evolutions in the React and Next.js ecosystems.

## 🛠️ Tech Stack

This project is built with a fast, modern frontend toolchain:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Package Manager & Runtime:** [Bun](https://bun.sh/)
- **Typography:** [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque)
